# Prasanna Pojgey | Portfolio Website

A personal portfolio website for showcasing work in embedded systems, IoT, firmware, and robotics.

## Overview

This repository contains a static website built with HTML, CSS, and JavaScript.

## Run Locally

1. Clone this repository.
2. Open index.html in a browser, or serve the folder with any local static web server.
3. Update project links and contact details in the website source before publishing.

## Repository Structure

| File | Purpose |
| --- | --- |
| index.html | Page structure and portfolio content |
| styles.css | Layout, typography, and responsive styling |
| script.js (filename currently has a trailing space) | Browser interactions |
